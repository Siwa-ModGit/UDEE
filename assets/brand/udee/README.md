# UDEE brand starter

Editable brand assets for **อยู่ดี — UDEE**, a home and condo rental project.

## Structure

- `udee-logo.svg`: horizontal vector wordmark and house symbol, with a transparent background for light surfaces.

## Usage

Reference the SVG as an image or import it through your application asset pipeline. Preserve its aspect ratio. When used as an HTML image, provide `alt="UDEE — อยู่ดี"`.

The lettering uses system fonts. For identical typography across devices, choose a licensed project font and convert lettering to outlines in a vector editor.
